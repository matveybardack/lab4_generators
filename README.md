# Generators Lab

Лабораторная работа №4: генераторы в Python.

## Описание

Небольшое приложение с графическим интерфейсом (PySide6, `QTabWidget`), реализующее три задания на генераторы:

1. **Задание №1.** Модули всех целых чисел из диапазона `[a; b]` (границы включаются). Выводятся первые четыре значения (или меньше, если диапазон короче).
2. **Задание №2.** Бесконечный генератор случайных паролей длиной 12 символов из набора: строчные и заглавные латинские буквы, цифры, спецсимволы `!?@#$*`. Выводятся первые пять паролей.
3. **Задание №3.** Попарные произведения элементов двух списков через `zip` и `map`. Выводятся первые три произведения, полученные тремя вызовами `next`.

Каждое задание выполняется через многопоточный генератор `ThreadedGenerator`: исходный генератор работает в отдельном потоке, значения передаются через ограниченную очередь. Вычисления в GUI выполняются в фоновом `QThread`, поэтому окно не зависает.

Стек: Python, PySide6, pytest, pytest-qt.

## Инструкции по запуску

Требуется Python 3.9 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запуск приложения:

```bash
python main.py
```

Запуск тестов:

```bash
pytest
```

## Краткая справка

### Вкладки

**Задание №1.** Поля `a` и `b` (целые числа). Кнопка «Выполнить» выводит модули первых четырёх чисел диапазона от `a` до `b` включительно. Требуется `a < b`.

**Задание №2.** Ввода нет. Кнопка «Сгенерировать» выводит пять паролей по 12 символов, кнопка «Очистить» очищает область вывода.

**Задание №3.** Два списка целых чисел. Кнопка «Выполнить» выводит первые три произведения `first[i] * second[i]`.

### Формат ввода

- Целое число: необязательный знак `+` или `-` и цифры, например `-5`, `42`. Дроби, экспоненциальная запись и буквы не допускаются.
- Список: числа через пробел и/или запятую, например `1, 2 3,4`.

### Возможные ошибки

| Ситуация | Сообщение |
|---|---|
| Пустое поле, не число | некорректный ввод (`InvalidInputError`) |
| `a >= b` | левая граница должна быть меньше правой (`InvalidRangeError`) |
| Пустой список, список короче двух элементов, разная длина списков | `InvalidListsError` |
| Произведений меньше трёх (списки из двух элементов) | `NotEnoughValuesError` |
| Обращение к остановленному генератору или превышено время ожидания | `GeneratorStoppedError` |

Ошибки показываются красной меткой под областью результата, приложение при этом не падает. Непредвиденные исключения перехватываются и показываются в диалоге.

### Особые случаи

- **Списки разной длины.** Не обрезаются, а приводят к исключению `InvalidListsError`. Список из одного элемента тоже недопустим.
- **Поведение после остановки потока.** После `stop()` вызов `next()` у `ThreadedGenerator` бросает `GeneratorStoppedError`. Исключение: если все данные уже были прочитаны, остаётся `StopIteration`. Повторный вызов `stop()` безопасен.
- **Таймаут.** Если рабочий поток не выдал значение за 5 секунд, потребитель получает `GeneratorStoppedError`.
- **Исключения из рабочего потока** повторно возникают в потребителе при вызове `next()`.
- Общая логика вкладок вынесена в `app/ui/base_tab.py`.
